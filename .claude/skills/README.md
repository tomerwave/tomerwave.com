# Writing skills

Copies of the two writing skills, kept here so they travel with the site.

**Source of truth is [github.com/tomerwave/skills](https://github.com/tomerwave/skills).**
Edit there, then copy the changed `SKILL.md` into this directory and into
`~/.claude/skills/` so all three stay in step.

- `technical-article-writer` writes the commercial articles that live in
  `src/content/blog/` and point at a service page.
- `personal-blog-writer` writes the personal posts, interview first.

A third skill, `tech-observation-posts`, lives in the skills repo only. It
writes LinkedIn reactions to news rather than anything on this site.
