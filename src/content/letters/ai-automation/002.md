This week the agent story got louder and more honest at the same time. Port mapped the infrastructure debt that appears after the demo. A YC CTO talked about agents rewriting code unprompted because the stack gave them too many toys. SAP is shipping agents that can run multi-step business work, which only helps if you already know which steps should never leave a human.

The pattern for operators is the same as last year, with sharper teeth. Automate the boring, stable path. Leave judgment-heavy, exception-heavy, or poorly measured work alone until you can see the failure modes.

The companion essay is a filter for which processes should not be automated yet, and what to fix first if you still want the leverage later.

> Tip: if you cannot write the rollback in one paragraph, you are not ready to let software own the happy path.
